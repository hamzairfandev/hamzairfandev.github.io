Trust center order crm wordpress/woocommerce plugin

I developed a website designed to streamline order management by integrating it with a CRM system. The primary functionality of the site is to match products with their corresponding SKUs from the CRM and place orders directly within the CRM system. I made an admin menu which requires to store the crm credentials.


This seamless process automates order placement, reducing manual errors and saving time for both the user and the business. The system also ensures that all orders are synchronized between the website and the CRM for efficient inventory and order management.
