Duffel Flights API Website


Developed a complete flight booking system in WordPress using the Duffel Flights API. The solution allows users to search flights, browse paginated offers, view detailed itineraries, add selected flights to WooCommerce as booking products, and create flight reservations through the Duffel Orders API.


Below is the explaining video


Features

  • Flight search using Duffel API
  • One-way and return flight support
  • Dynamic airport autocomplete
  • Flight offer pagination using cursors
  • Detailed itinerary page
  • Airline logos, baggage, aircraft, cabin class, duration, and traveller information
  • Add flight bookings to WooCommerce cart
  • Dynamic cart and checkout data
  • Flight information stored with WooCommerce order items
  • Order validation against expired flight offers
  • Automatic cleanup of expired search results using WP-Cron
  • Duffel Hold Order API integration
  • Admin order management with complete API response logging
  • AJAX-powered booking flow
  • Object-oriented WordPress plugin architecture

Technologies Used

  • WordPress
  • WooCommerce
  • PHP (OOP)
  • REST API
  • Duffel Flights API
  • AJAX
  • MySQL
  • JavaScript / jQuery
  • WP Cron
  • WordPress Hooks & Filters

Technical Highlights

  • Built a custom WordPress plugin from scratch.
  • Implemented cursor-based pagination for flight offers.
  • Cached search results locally to minimize API requests.
  • Added automatic expiry validation before checkout.
  • Designed a custom WooCommerce booking flow using a single hidden product.
  • Stored complete booking metadata within WooCommerce orders.
  • Implemented scheduled cleanup of expired cached searches.
  • Integrated Duffel Hold Orders API for reservation creation.
  • Maintained compatibility with WooCommerce checkout and order lifecycle.

What I Solved

  • Efficiently handled large flight search responses.
  • Reduced unnecessary API calls through local caching.
  • Prevented bookings of expired offers.
  • Converted flight offers into WooCommerce order items while preserving all itinerary information.
  • Built a scalable, maintainable plugin using object-oriented architecture.
